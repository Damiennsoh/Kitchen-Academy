# PWA Icons - Placeholders

The following icon files are needed for the PWA to function properly:

## Required Icons

1. **icon-192.png** - 192x192 pixel PNG icon for mobile devices
2. **icon-512.png** - 512x512 pixel PNG icon for high-resolution displays

## Icon Requirements

- Format: PNG
- Background: Brand color (#f97316 - orange)
- Icon: Chef hat or cooking-related symbol
- Style: Clean, modern, recognizable at small sizes
- Text: Optional "C" or "CK" for brand recognition

## How to Create Icons

1. Use design tools like Canva, Figma, or Adobe Illustrator
2. Create a square canvas (192x192 and 512x512)
3. Use the brand orange color (#f97316) as background
4. Add a simple chef hat or cooking icon in white
5. Export as PNG
6. Replace the placeholder files in the public folder

## Temporary Solution

For development, you can use any PNG image as a placeholder by:
1. Finding any square PNG image
2. Resizing it to 192x192 and 512x512
3. Naming them icon-192.png and icon-512.png
4. Placing them in the public folder

The application will work without these icons, but the PWA install experience will be less optimal.
